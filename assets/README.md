# Örnek varlıklar

- `brand/logo.svg`: Nedenmiş için düzenlenebilir vektör kanal işareti.
- Referans ses dosyanız arayüzden yüklendiğinde uygulamanın kullanıcı veri klasöründeki `storage/assets/reference_voice.wav` konumuna dönüştürülür. Geliştirme modunda bu klasöre `assets/reference_voice.wav` koymanız da ilk açılışta algılanır.

Gizlilik nedeniyle kişisel referans ses kayıtları ve `.env` dosyaları Git'e eklenmez. Uygulama hiçbir sağlayıcı yapılandırılmadan prosedürel görseller ve yerel proje yönetimiyle açılabilir.
